DIHO KASIR PRO - Paket tampilan dashboard

File:
- index.html: halaman web yang menampilkan desain dashboard sesuai gambar.
- dashboard.png: gambar dashboard asli yang digunakan.

Cara pakai GitHub Pages:
1. Ekstrak ZIP.
2. Unggah index.html dan dashboard.png ke root repository GitHub.
3. Commit changes.
4. Pastikan GitHub Pages aktif dari branch main, folder /(root).

Catatan: paket ini mereproduksi gambar dashboard secara visual. Elemen pada gambar bukan tombol aplikasi interaktif.
